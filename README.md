# Sri Ganesh Ganta — Portfolio

Built with Vite 4 + React 18 + React Router 6, using the Halcyon design system.

## Dev setup

> Run these commands from the Protofolio folder

```bash
# 1. Install deps (requires Node 18+)
npm install

# 2. Start dev server
npm run dev
# → http://localhost:5173

# 3. Build for production
npm run build
# → dist/
```

## Deploy (Vercel — recommended)

1. Push this folder to a GitHub repo
2. Import the repo at vercel.com/new
3. Framework: Vite (auto-detected)
4. Hit Deploy — done

## Pages

- `/`        Home (Hero, Selected Work, About strip, Resume strip, Contact)
- `/about`   Full about page with bio, stats, principles
- `/resume`  Full résumé with experience, skills, education
